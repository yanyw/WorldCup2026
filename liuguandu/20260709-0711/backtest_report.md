## 二、预测方法论

### 核心算法: Dixon-Coles 联合校准

```
1. Poisson λ 初始化: λ_h, λ_a ← 从 Elo 转换
2. 预计算缓存: P(k | λ) = e^(-λ)·λ^k/k!, 递推 P(k+1)=P(k)·λ/(k+1)
3. Dixon-Coles 联合概率: P(g_h, g_a) = τ_{λ_h,ρ}(g_h,g_a) · τ_{λ_a,ρ}(g_a,g_h) · (1-ρ)  [ρ < 0 减相关性]
4. 网格搜索: λ_h × λ_a × ρ ∈ [-0.08, +0.08] → 最小化加权 Loss
5. Loss = w_1x2·MSE(1X2) + w_tot·MSE(O2.5) + w_btts·MSE(BTTS) + w_spread·MSE(Spread)
```

### 仓位管理: Kelly 公式

```
Buy edge > 0:  f* = (p_model - p_mkt) / (1 - p_mkt)
Sell edge > 0: f* = (p_mkt - p_model) / p_mkt
Amount = 0.25 × f* × $10,000  (风险折扣 25%)
Cap: 单笔 ≤$200, 总敞口 ≤$1,000
```

1. **BTTS 预测偏保守**: QF3 和 QF4 都赌 BTTS=NO，但实际四场中有三场 BTTS=YES。淘汰赛阶段的 BTTS 率可能高于模型预期（紧张局面下防守失误增多、加时赛增加进球）
