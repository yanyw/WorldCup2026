## 新增的合理构型

### 1. 最小 KL 最大熵比分矩阵

先用 Dixon–Coles 生成基础比分分布 `q(i,j)`，再求解：

`min Σ p(i,j) log[p(i,j)/q(i,j)]`

约束为 1X2 与大 2.5 的概率等于独立传统赔率和历史模型的融合目标。解具有指数倾斜形式：

`p(i,j) ∝ q(i,j) exp(θ' f(i,j))`

它的意义是：在满足可观测主盘口约束的所有比分矩阵中，选择对基础进球模型改动最小的一项，避免分别拟合各盘口后出现概率不相容。

### 2. 共同比赛节奏混合

普通独立 Poisson 隐含进球方差等于均值，容易低估“双方一起沉闷”或“比赛一起打开”的概率。v5 引入共同节奏变量：尺度 0.72、1.00、1.28，权重 0.255、0.49、0.255，均值仍为 1。内部 2014 年以来世界杯 290 场样本的总进球方差/均值约为 1.11，因此使用小幅共享过度离散，而不是任意加厚尾部。

### 3. 模型规格集合，而非单点参数

对传统赔率权重、两家独立赔率源、Dixon–Coles 基础矩阵和节奏混合矩阵做 10 个规格组合。交易判断使用规格分布的第 10 百分位，而非中心概率；标准盘、比分盘、半场/加时盘分别要求 2%、3%、4% 的稳健边际。

### 4. 衍生盘口专属外部锚

1X2 和大小球无法唯一决定“上半场双方均进球”。因此同类传统盘口存在时，以 90% 权重锚定其去水概率，比分模型只保留 10% 权重。Betfair 的上半场 BTTS 为 Yes 4/1、No 1/7：原始隐含概率 0.20 与 0.875，去水后的 No 为 `0.875 / 1.075 = 81.395%`。这直接否定了 Polymarket No 0.82 的表面机会。[Betfair 全市场页面](https://www.betfair.com/betting/football/fifa-world-cup/england-vs-argentina/e-35815366?tab=all-markets)

### 5. 全状态线性规划套利扫描

不再只检查 YES+NO 或几个手写组合。将每个可由最终比分决定的合约写成 156 个状态上的 0/1 赔付向量，用线性规划寻找“每个状态至少赔 1 美元”的最低含费组合。最低成本仍为 1.001150，说明当前不存在被简单组合扫描漏掉的多腿 Dutch book。

### 6. 等价事件图与触发式对冲

西班牙已经进入决赛，因此以下三个合约是同一状态：英格兰晋级、决赛 ESP–ENG、三四名赛 FRA–ARG；对应的三个阿根廷状态互为补集。该结构允许跨事件比价，也产生本次唯一的正触发组合。

## 执行建议

### A. 触发式准套利（只适合自动化）

| 操作 | 条件 |
|---|---|
| 第一步 | BUY YES “Final ESP–ENG”限价 0.52，必须 maker only |
| 第二步 | 第一步完全或部分成交后，立即检查“England to advance NO”卖价 |
| 对冲触发 | 卖价 ≤ 0.4675 时，按相同份数买 NO；快照价为 0.4625 |
| 取消条件 | 对冲卖价 > 0.4675、盘口暂停、手续费结构改变，均不得把它记作套利 |
| 容量 | 0.52 同价已有约 1.61 万美元买盘；对冲最优价深度约 30.01 万美元 |
| 仓位 | 无自动化监控则为 0；有自动化时单次第一腿最多为本金的 0.25%，未完成对冲不得重复加仓 |
