# Polymarket 世界杯预测研究方案 v2

## 1. 研究目标与可证伪假设

目标是在真实可成交成本下，检验独立国家队模型是否能识别 Polymarket 的系统性定价偏差。核心假设为：模型相对 Polymarket 的稳健偏差能够改善样本外 Brier/Log Loss，并在费用、价差和滑点后产生正期望。

若模型不优于去水后的传统赔率基准，或偏差信号不能预测结算结果，则拒绝该假设。不能用少数世界杯交易或单场命中宣称有效。

## 2. 从原方案和 GitHub 研究吸收的内容

### 保留

- Elo、时间衰减攻防泊松、Dixon–Coles低比分修正。
- 用统一比分矩阵推导胜平负、大小球、让球、BTTS和正确比分。
- 严格时间截止、原始数据快照、概率校准、交易成本和分数Kelly。
- `liuguandu` 的多盘口一致性和自动报告思路。
- `yanyawei` 的信息血缘隔离、外部赔率去水、概率区间和保守执行纪律。

### 修正

- 不使用 Polymarket 同时校准模型并检验 Polymarket。
- 第一阶段只用国家队比赛；五大联赛俱乐部数据不能直接作为国家队攻防训练样本。
- 当前世界杯样本极小，暂不上XGBoost；没有通过滚动验证前，复杂模型只作为challenger。
- Kelly基于稳健下界，而不是点估计；未完成充分验证时只使用5% Kelly，单笔上限0.75%。
- 不把mid价当作可成交成本。没有订单簿时统一扣除2pp执行缓冲，低置信度盘口再扣2pp。

## 3. 生产轻量模型

### P1：国家队时间衰减攻防模型

以2014年至预测截止日前的国家队比赛拟合：

`log(lambda_home) = mu + home_adv + attack_home - defence_away`

`log(lambda_away) = mu + attack_away - defence_home`

使用4年半衰期、ridge收缩以及赛事权重。世界杯、洲际大赛、预选赛和友谊赛权重不同。随后在历史样本上估计Dixon–Coles `rho`。

### P2：顺序Elo审核

从历史比赛逐场更新Elo，任何一场预测只使用此前结果。用多项逻辑校准把Elo差映射为胜/平/负。P2只审核1X2，不伪造总进球或BTTS。

### B1：传统赔率基准

冻结赛前的1X2和直接大小球赔率，等比例去水。博彩公司和Opta属于同一市场知情簇，不能重复满权重。

### 一致比分融合

先将P1和P2形成独立1X2，再使用：

`p_target = p_sharp + reliability * (p_independent - p_sharp)`

当前 `reliability=0.30`。最后重新拟合一组Dixon–Coles进球参数，使胜平负与大2.5同时接近融合目标，从而保持所有盘口数学一致。

## 4. 不确定性与交易规则

围绕最终进球总量、双方进球份额和`rho`生成75个确定性情景，使用第10/90百分位作为风险边界。

- BUY YES稳健边际：`p10 - ask - execution_buffer`
- BUY NO稳健边际：`(1-p90) - no_ask - execution_buffer`
- 入选要求：稳健边际至少5pp。
- 半场、加时、点球和晋级市场额外扣2pp。
- 使用5% Kelly；单笔最多资金0.75%。
- 无真实bid/ask深度时，所有结果仅为纸面研究信号。

## 5. 验证协议

当前版本提供固定时间留出：2024年前训练，2024年至截止日验证，报告Log Loss、multiclass Brier和RPS。它是基线审计，不等于正式最终回测。

正式下一阶段必须增加：

1. 扩展窗口walk-forward，每个折重新拟合模型；
2. 验证集选择半衰期、ridge和融合权重；
3. 完全冻结的最终holdout；
4. 历史Polymarket赛前订单簿与实际成交模拟；
5. 模型、传统赔率、Polymarket三者的概率精度比较；
6. 多重筛选、bootstrap、去掉最赚钱5笔后的稳健性测试。

## 6. 暂缓模块

- XGBoost：等国家队特征具备严格point-in-time时间戳并完成基础模型最终holdout后再加入。
- 球员级xG/首发：需要可靠、可复现、赛前可得的数据源。
- 角球、牌数、首个进球者：必须有专项模型和同盘口验证。
- 自动交易：在纸面跟踪、订单簿回放和小额实测前不启用。

## 7. 当前交付标准

每次预测必须保存配置、比赛输入、数据截止日、训练样本最后日期、P1/P2中间值、传统赔率去水值、最终比分矩阵、全部盘口估值、p10/p90、执行缓冲、稳健边际和PASS理由。
