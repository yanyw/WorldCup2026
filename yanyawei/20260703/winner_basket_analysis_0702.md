# 法国、阿根廷、西班牙、英格兰冠军合约各买1份分析

- **Polymarket快照**：2026-07-02 16:02 UTC
- **Opta淘汰树更新时间**：2026-07-02 06:31 UTC
- **交易定义**：四队World Cup Winner YES各买1份
- **结算**：四队最多只有一队夺冠；任一队夺冠总兑付1 USDC，否则兑付0

## 结论

当前不建议以taker方式执行“四队各买1份”。

- 四份合约ask合计71.6c。
- taker费用合计1.630c。
- 总成本73.230c，即联合夺冠概率必须超过73.23%才有正期望。
- Opta当前25,000次淘汰赛模拟给四队联合概率64.44%，对应期望亏损8.79c/组，ROI约-12.0%。
- Polymarket全部22支存续球队去水后，四队联合概率70.73%；即使完全相信市场，ask价差和费用后仍预期亏2.50c/组。
- 纯FIFA小样本模型给42.99%，但该模型明显高估加拿大、美国等队，不能作为中心估计，只作为向下压力测试。

组合中的负价值主要来自法国和阿根廷；西班牙按Opta有轻微正Edge，英格兰接近公平。

## 三类概率模型

### 1. 纯FIFA攻防淘汰树

输入是56份FIFA比赛报告中的xG和实际进球。每队攻防强度通过带L2收缩的Poisson模型估计，进球率使用`85% xG + 15%实际进球`。每场按以下顺序计算晋级：

1. 90分钟独立Poisson比分。
2. 平局后，以原进球率的三分之一模拟30分钟加时。
3. 加时仍平时，点球大战双方各50%。
4. 按当前淘汰赛树精确传播，不使用Monte Carlo抽样噪声。

模型确认的主要路径：

- 法国与巴拉圭、加拿大/摩洛哥同区，潜在半决赛对手包括西班牙。
- 西班牙先对奥地利，晋级后面对葡萄牙/克罗地亚胜者。
- 英格兰先对墨西哥，所在半区可能遇到巴西及阿根廷。
- 阿根廷先对佛得角，之后进入澳大利亚/埃及、哥伦比亚/加纳所在四分之一区域。

纯内部冠军概率：

| 球队 | 冠军概率 |
|---|---:|
| 法国 | 13.21% |
| 西班牙 | 12.75% |
| 英格兰 | 9.21% |

该结果不能直接作为公平概率。模型只使用本届世界杯56场小样本并进行强收缩，却给加拿大5.78%、美国7.11%的冠军率，远高于市场，说明它没有足够的长期实力和球员质量先验。连续四轮淘汰会放大单场评级误差，因此仅保留为压力测试。

## Maker情景

若四份都能在当前bid成交，成本约71.2c且maker不收费。Opta基准下：

`EV_maker = 64.44c - 71.2c = -6.76c`

maker仍是负期望，而且四条腿未必同时成交；只成交部分会改变篮子结构。因此不建议通过挂maker把负价值篮子包装成可交易机会。

## 决策建议

1. **不执行四队各买1份的taker篮子。** 当前总成本73.23c显著高于Opta 64.44%的联合概率。
2. **不以等份额方式加入法国和阿根廷。** 这两条腿是负Edge的主要来源。
3. 若一定要保留冠军敞口，当前公开模型只支持把西班牙作为小额观察仓位；英格兰接近公平，尚无足够安全边际。
4. 西班牙即将比赛，冠军价格会随晋级结果跳变。任何下注必须重新刷新Opta和CLOB，不能沿用本快照。
5. 冠军合约与已有单场下注属于同一赛事风险，不能简单叠加为“更多分散”。
