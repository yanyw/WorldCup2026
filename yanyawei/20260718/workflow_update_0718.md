# 2026-07-18 工作流增量

本文件是在 `20260709`、`20260711` 和 `20260715` 流程上的增量，不替换原流程。

## 流程

1. **先复盘**：读取上一轮最终成交清单，按 90 分钟赛果结算；概率评分使用 `p_center`，交易执行评分使用当时 `p_trade - cost`。
2. **锁定比赛**：只处理未来两日且 Polymarket 已有可执行盘口的比赛。
3. **防未来数据**：内部模型只读取开赛前已完成的 90 分钟结果；加时赛必须由独立来源校正。
4. **内部模型**：
   - P1：时间衰减、ridge 收缩的攻防 Poisson。
   - P2：顺序 Elo 加多分类校准，只调整双方强弱比例。
   - P3：FIFA 当前届比赛 xG 的对手调整模型，权重上限 25%。
5. **适用域检查**：模型缺失关键结构变量且没有事前回测的替代权重时，触发证据门否决；不能看到价格后临时选择精确降权系数。
6. **外部概率**：每家完整双向或三向报价分别去水，再跨来源平均；Opta 只进入 1X2，Polymarket 不进入公允概率。
7. **双向融合**：
   - 1X2：`p_external = 75% * sportsbook + 25% * Opta`。
   - 大小球：`p_external = sportsbook`。
   - `p_center = p_external + w_internal * (p_internal - p_external)`。
8. **动态折扣**：`u = max(0.5pp, 0.5*机构离散度 + 0.1*内外分歧 + 数据质量惩罚)`，`p_trade = p_center - u`。
9. **执行成本**：
   - taker：订单簿 VWAP 加 `feeRate * price * (1-price)`。
   - maker：只允许 post-only，maker fee 为 0 时成本为限价。
10. **门槛**：费用与不确定性之后 `robust edge >= 1.5pp` 才可下注。
11. **组合去重**：同场互补、包含或高度相关合约先按事件簇合并；不能把法国不胜与英格兰胜当成两场分散下注。
12. **两轮审核**：审核代理提出漏洞，分析代理逐条接受或拒绝；返修后再审核一次。

## 0718 的方法变化

新增“模型适用域证据门”，原因是法英季军赛的通用内部模型给小 2.5 球 59.58%，而机构去水概率仅 34.44%。这种分歧主要来自内部模型没有季军赛阶段、轮换和动机变量，不应被解释为可直接下注的巨大 edge。

第一版曾尝试把季军赛 1X2 权重设为 12.5%、大小球设为 0。审核指出这是看到当期分歧后提出，存在事后调参嫌疑，因此正式版拒绝这两个精确权重。最终版仍按 25% 计算诊断概率，但法英全部直接盘口统一标记 `SKIP_EVIDENCE_GATE_STAGE_OOD`，不进入执行层。未来若建立并事前回测专门的季军赛模型，才可重新开放。

## 输出要求

最终报告必须对每个正式下注给出完整链条：P1/P2/P3 中间结果、最终 lambda、内部概率、机构去水概率、Opta、融合中心、每项不确定性、`p_trade`、订单簿、费用、robust edge、执行方式和仓位。没有正式下注时，对最接近门槛的候选提供同样链条，并给出条件限价。
